# EditImageContext

\
interface [EditImageContext](index.md) : [ImageWorkflowContext](../image-workflow-context/index.md)

Interface for Edit Image workflow context operations. This context provides access to workflow-specific functionality for the Edit Image workflow, allowing clients to interact with the active editing session.

Inherits the shared image-module operations (`hasUnsavedChanges`, `getAsset`, `updateMobileToolbarOptions`) from [ImageWorkflowContext](../image-workflow-context/index.md).
